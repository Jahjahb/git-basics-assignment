# Git Basics Assignment
Explaining pull, fetch, push, merge, commit, fork, clone and branches 

## 1. Pull
`git pull` downloads changes from a remote repository and integrates them into your current local branch. It helps keep your local project up to date.

## 2. Fetch
`git fetch` downloads new changes and information from a remote repository without merging them into your current branch. This lets you review updates before applying them.

## 3. Push
`git push` uploads your local commits to a remote repository, such as GitHub. It allows you to share your changes with other people.

## 4. Merge
`git merge` combines changes from one branch into another branch. If both branches change the same lines differently, you may need to resolve a merge conflict.

## 5. Commit
`git commit` saves a snapshot of your staged changes in your local repository's history. Each commit includes a message describing the changes.

## 6. Fork
A fork is a copy of another person's repository under your own GitHub account. It allows you to make changes independently and propose contributions to the original project.

## 7. Clone
`git clone` downloads a copy of a remote repository onto your computer. It includes the project's files and Git history so you can work locally.

## 8. Branches
Branches allow developers to work on different features or changes without immediately affecting the main branch. They make it easier to experiment, collaborate, and organize development.
